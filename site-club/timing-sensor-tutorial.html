Setting the timing sensor

Fitting the ignition timing sensor, finding the magnet ignition point, and adjusting ignition advance into range.

Guide

Setting the timing sensor

Difficulty: Advanced Time: ~30 min Applies to: Gas boards Last updated: Sep 2026

Watch the walkthrough

Watch on YouTube ↗ · JETSURF tuning. Timestamps in the steps below follow the video's on-screen counter (0:00–3:14).

The timing sensor sets the engine's ignition advance. This is a measure-and-adjust job — you find the magnet's zero point, rotate slowly to top dead center, read the advance value, and nudge the sensor until it lands in range. You need a way to read the advance value off the board.

Tools & supplies

  • Medium-strength (blue) Loctite
  • Bright light source (to spot the magnet ignition point)
  • Diagnostic tool / reader for the ignition advance value
  • The timing carrier / rotation tool

Fit the sensor

  1. 0:00 — Secure the sensor bolts with medium-strength Loctite.
  2. 0:19 — Set the timing sensor roughly in the center of its adjustment range.
  3. 0:39 — Connect the wiring to both the sensor and the ECU.

Find the ignition point

  1. 1:02 — Using a light source, locate the magnet ignition point.
  2. 2:01 — If you rotate past the magnet position, start the rotation over from the beginning.
  3. 2:22 — With the exact 0.00 position on the magnet identified, slowly rotate the carrier toward top dead center (TDC).
  4. 2:30 — Move very slowly so you can read the exact value at which the reading stops.

Read & adjust the advance

  1. 2:38 — Read the ignition advance value. (In the video's example it measured 0.107.)
  2. 2:45 — Check it against spec: acceptable range 0.080–0.160, optimal 0.120.
  3. 3:03 — Adjust by moving the timing sensor: right decreases the value, left increases it.
  4. 3:14 — Move the sensor gradually and re-measure until you reach the target advance, then lock it down.
Ignition advance spec: acceptable 0.080–0.160 · optimal 0.120. Right = less advance, left = more. Adjust in small increments and re-read after every move.
Caution: the reading is only valid if you approach TDC slowly and from the magnet's 0.00 point — rush it or overshoot and the value is meaningless, so restart the rotation. Don't ride on an advance value outside 0.080–0.160.
